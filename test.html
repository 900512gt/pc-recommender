PC 零件口碑 — Widget 測試頁

右下角圓形按鈕即為浮動聊天 widget。 頁面本身使用 Georgia 字型與淺色系，用來驗證 Shadow DOM 樣式隔離： widget 不應該繼承這頁的任何 CSS。

啟動步驟

1

確認 .env 中已設定 OPENAI_API_KEY。

2

安裝後端依賴（若尚未安裝）：
pip install fastapi uvicorn python-multipart

3

從專案根目錄啟動後端：
python src/rag/server.py

4

以瀏覽器開啟此頁面（直接開檔案或用任意 HTTP server 都可）。

5

點擊右下角按鈕，試點範例 chip 或輸入問題，驗證串流回答。

⚠️ 嵌入其他網站時，將 <script src="..."> 的來源改為你的伺服器網址， 並在載入前設定 window.PCRAG_API_BASE = "https://your-server.com"。
