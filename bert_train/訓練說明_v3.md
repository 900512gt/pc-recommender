# BERT 面向情感 v3 訓練說明（2026-10-21）

## 這次改了什麼

教授 10/20 認為「未提及」比例太高（val／test 約 93%）。他的意思是：**只訓練有評價的評論**。相關評論一定對型號有評價，未提及的樣本會從同一則評論的其他面向自然產生，不需要再把不相關評論放進來。

所以 v3 的訓練資料：

1. **拿掉不相關評論**（27,720 則）：原本全部標「未提及」當負例。
2. **每則相關評論多標一個「總體」面向**：對指定型號的整體態度，已用 gpt-5.4-nano 標好，在 `aspects_總體_p4.jsonl`。
3. **只留至少一個面向（含總體）有評價的評論**：被判成相關、但所有面向都未提及的 4,674 則也拿掉，它們多半是提問、資訊，或相關性判斷本身有誤。

| | 舊資料 `aspect_dataset/` | v3 `aspect_dataset_v3/` |
|---|---|---|
| 進入訓練的評論 | 含不相關評論 | 20,299 則（都至少有一個面向有評價） |
| val 未提及比例 | 93.5% | 76.3% |
| test 未提及比例 | 93.3% | 75.9% |
| train 正負評樣本 | 約 1.7 萬 | 約 2.9 萬 |

train／val／test 的切分和舊資料相同（先對全部資料以討論串切分，再拿掉評論），所以新舊模型可以比較。

### 拿掉的評論變成兩份獨立的測試集

拿掉的評論裡，落在 test 討論串的另外存成兩份測試集，**答案全部是未提及**，用來檢查拿掉它們的副作用：

| 測試集 | 內容 | 用來看 |
|---|---|---|
| `test.jsonl`（主要） | 至少一個面向有評價的評論 | 正負評的 precision、recall |
| `test_no_opinion.jsonl` | 相關但所有面向都未提及 | 模型會不會把提問、閒聊判成有評價 |
| `test_irrelevant.jsonl` | 不相關評論 | 相關性過濾漏掉時，模型會不會誤判 |

後兩份沒有正負評的答案，評估時看**誤判率**：判成正面或負面的比例，越低越好。

推論時的前提：模型只學過「有評價的評論」，判斷新評論前要先做相關性過濾。這兩份測試集就是在量化「過濾不乾淨時會怎樣」。

## 需要的程式版本

分支 `aspect-sentiment-rebuild`，pull 最新版即可：

```
git checkout aspect-sentiment-rebuild
git pull
```

環境和上次相同：PyTorch（CUDA 版）、`transformers`、`scikit-learn`。

## 步驟

以下指令都在 `bert_train/` 底下執行。

### 1. 建立 v3 資料（約 10 秒）

資料夾不進版控，要自己產生：

```
python build_aspect_dataset.py --drop-irrelevant --overall aspects_總體_p4.jsonl --drop-no-opinion --output-dir aspect_dataset_v3
```

對一下輸出的樣本數，一樣代表資料和原作者那邊相同（也可以對照 `aspect_dataset_v3_建立紀錄.txt`）：

| | 樣本數 | 未提及 | 正面 | 負面 |
|---|---|---|---|---|
| train | 115,568 | 86,676 | 15,477 | 13,415 |
| val | 12,237 | 9,341 | 1,628 | 1,268 |
| test | 14,855 | 11,268 | 1,973 | 1,614 |
| test_no_opinion | 3,317 | 全部 | — | — |
| test_irrelevant | 21,636 | 全部 | — | — |

選做：另建一份「未提及：正負評 = 8:1」的資料，比較減量比例的影響：

```
python build_aspect_dataset.py --drop-irrelevant --overall aspects_總體_p4.jsonl --drop-no-opinion --neg-ratio 8 --output-dir aspect_dataset_v3_r8
```

### 2. 試跑（幾分鐘）

```
python train_aspect.py --model ckip --sample 2000 --epochs 1 --data-dir aspect_dataset_v3 --save-dir runs/smoke
```

確認三件事：沒有報錯、loss 有往下降、每輪的「預測分布」裡正面和負面不是 0。

### 3. 正式訓練

時間約是上次的 1.7 倍（train 從 6.7 萬筆變成 11.6 萬筆），訓練完會自動評估 test、test_hard、test_no_opinion、test_irrelevant。

```
python train_aspect.py --model ckip --epochs 4 --data-dir aspect_dataset_v3 --save-dir runs/v3_r3
```

有做 8:1 的話：

```
python train_aspect.py --model ckip --epochs 4 --data-dir aspect_dataset_v3_r8 --save-dir runs/v3_r8
```

`--save-dir` 指定的資料夾已經有模型時，程式會停下來不覆蓋；確定要覆蓋才加 `--overwrite`。`runs/` 不進版控。

### 4. 舊模型在 v3 上重新評估（不訓練）

```
python train_aspect.py --eval-only --model-dir <上次的模型資料夾> --data-dir aspect_dataset_v3
```

上次的模型是 `20261006_ckip_4輪` 那次訓練存的 `bert_ckip_aspect/`。結果存成該資料夾裡的 `eval_aspect_dataset_v3.json`，不會動到原本的 `result.json`。

**這一步一定要做。** v3 的 test 拿掉了容易的未提及樣本，分數一定比上次高，所以新模型要和「舊模型在 v3 test 上的分數」比，不能和上次的 Macro-F1 0.708 比。

### Windows：log 存成 UTF-8

上次 PowerShell 存的 `train_log.txt` 是 UTF-16，中文變成亂碼。這次先設定編碼，再用 cmd 轉存：

```
$env:PYTHONIOENCODING="utf-8"
cmd /c "python -u train_aspect.py --model ckip --epochs 4 --data-dir aspect_dataset_v3 --save-dir runs/v3_r3 > train_log_v3_r3.txt 2>&1"
```

## 怎麼看成績

### 主要測試集 `test`

- **「不含總體」這一行**：舊模型沒學過總體，新舊比較看這一行。
- **分項成績**：依來源、類別、「類別 面向」列出，每項都有正面／負面的 precision 與 recall。「GPU 穩定」和「CPU 穩定」分開列。
- 某一類完全沒有答案或沒有預測時印「-」。樣本很少的分項分數不穩，參考就好。

### `test_no_opinion`、`test_irrelevant`

- 印的是**誤判率**，以及判成正面、負面各佔多少，並分來源、類別列出，最後列出誤判率最高的面向。
- `test_irrelevant` 另外依 `p3_had_opinion` 分開：不相關卻曾被 p3 標過正負評的評論，答案「未提及」本身比較可疑，這部分的誤判率參考就好。
- 原作者用舊模型抽 300 筆試跑：兩份的誤判率都約 6～7%（樣本小，僅供參考）。

### 目標

上次（舊資料、舊 test）：正面 precision 0.52／recall 0.73，負面 0.45／0.69，Macro-F1 0.708，正負向正確率 0.86。目前主要問題是 **precision 低**：模型太常把未提及判成有評價。

| 指標（都在 v3 上比） | 目標 |
|---|---|
| test：正面、負面 precision | 從約 0.5 提升到 **0.6 以上** |
| test：正面、負面 recall | 維持 0.6 以上 |
| test：Macro-F1（不含總體） | 高於舊模型 |
| test：正負向正確率 | 維持 0.86 左右 |
| test_no_opinion、test_irrelevant 誤判率 | **不明顯高於舊模型**。新模型沒看過這兩種評論，誤判率可能會上升，上升多少就是拿掉它們的代價 |
| 總體面向 | 單獨看即可。總體標註本身的一致率只有約 6 成多（與人工判斷比對），BERT 很難超過標註品質 |

### 正常與異常

- val 分數第 2 輪之後持平：上次也是這樣，屬於正常，程式會留下 val Macro-F1 最好的那一輪。
- 每輪「預測分布」的正面、負面接近 0：模型全部猜未提及，資料或設定有問題。
- loss 變成 nan：程式會自動停下，可以試 `--lr 1e-5`。

## 兩個規則

1. **3:1 和 8:1 要選哪個，看 val，不看 test。** test 只用來報告最後的成績；看 test 選比較高的那個，等於偷看答案。
2. **調門檻的 `--eval-test` 先不要跑。** test 只能用一次，等方向確定再說。

## 跑完要回傳的

- `runs/v3_r3/result.json`（有做 8:1 的話也要 `runs/v3_r8/result.json`）
- 舊模型資料夾裡的 `eval_aspect_dataset_v3.json`
- 訓練 log（`train_log_v3_r3.txt` 等）
- 在 `BERT訓練成果_20261010/實驗紀錄.md` 加一行

模型檔（`model.safetensors`，約 400 MB）先不用傳，之後需要再用雲端硬碟。
